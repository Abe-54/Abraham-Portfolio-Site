# Project: Abraham Rubio — Portfolio

A fast, static personal portfolio (Astro 5 + TypeScript + Tailwind v4 + minimal React islands + Motion) for a full-stack developer who also makes indie games and builds with AI assistance.

## Design Context

### Users
- Recruiters, hiring managers, and engineering leads evaluating Abraham quickly (often skimming on desktop, sometimes mobile) to answer "can this person build real, shippable software?"
- Potential clients and collaborators gauging range (full-stack web + game dev).
- Fellow developers and gamers who will appreciate craft and personality.
The job to be done: in under a minute, communicate competence, current role (NJDCA), range (full-stack + indie games), and a modern AI-assisted workflow — then make it easy to reach out or download the resume.

### Brand Personality
Three words: **engineered, playful, precise.** The voice is confident but not boastful, technical but human, with a wink of arcade fun. It should feel like a senior-leaning developer who ships, takes craft seriously, and clearly enjoys games. Emotional goal: trust first, delight second.

### Aesthetic Direction
- **Dark-first** with a light toggle. The dark surface is a deep blue-tinted near-black (never pure black), derived from the existing brand blue (#599fc0).
- **Refined professional base, subtle gaming accents.** Gaming flair is seasoning, not the meal: a pixel/arcade micro-typeface (Silkscreen) only on small HUD labels (section indices, year markers, tags), keycap-style tactile button feedback, and one signature moment — a **gooey/metaball navigation** where the active indicator morphs between items.
- **Palette:** blue brand evolved into a perceptually-uniform OKLCH scale with neutrals tinted toward the blue hue, plus a single **warm arcade amber/orange accent** used at ~10% visual weight (active states, focus, key CTAs).
- **Typography:** Hubot Sans (expressive display) + Mona Sans (refined body) + Silkscreen (sparingly, pixel HUD labels). Fluid `clamp()` headings, body capped ~70ch, slightly looser line-height on dark.
- **Anti-references:** generic AI-slop dev portfolios — cyan-on-black neon, purple→blue gradient hero text, identical icon-topped feature cards, glassmorphism everywhere, fake stat/sparkline decoration, colored left-border stripes. None of these.
- **Motion:** balanced — one orchestrated, staggered page-load reveal and satisfying tactile feedback on the nav/buttons; restrained elsewhere. Honor `prefers-reduced-motion`.

### Design Principles
1. **Professional first, game flair as seasoning.** If a gaming touch undercuts credibility, cut it.
2. **One signature moment.** The gooey nav carries the personality; everything else stays calm so it lands.
3. **Fast and quiet.** Static output, self-hosted fonts, transform/opacity-only animation, no heavy JS where CSS will do.
4. **Real content over filler.** Copy reflects the actual NJDCA role, AI-assisted workflow, and shipped projects — no lorem, no invented achievements.
5. **Hierarchy through type, space, and rhythm** — not boxes. Avoid wrapping everything in cards; use asymmetry and varied spacing.
