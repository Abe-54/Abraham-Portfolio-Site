# Project: Abraham Rubio — Portfolio

A fast, static personal portfolio (Astro 5 + TypeScript + Tailwind v4 + minimal React islands + Motion) for a full-stack developer who also makes indie games and builds with AI assistance.

## Design Context

### Users
- Recruiters, hiring managers, and engineering leads evaluating Abraham quickly (often skimming on desktop, sometimes mobile) to answer "can this person build real, shippable software?"
- Potential clients and collaborators gauging range (full-stack web + game dev).
- Fellow developers and gamers who will appreciate craft and personality.
The job to be done: in under a minute, communicate competence, current role (NJDCA), range (full-stack + indie games), and a modern AI-assisted workflow — then make it easy to reach out or download the resume.

### Brand Personality
Three words: **engineered, playful, precise.** The voice is confident but not boastful, technical but human, with a wink of arcade fun. It should feel like a senior-leaning developer who ships, takes craft seriously, and clearly enjoys games. Emotional goal: trust first, delight second.

### Aesthetic Direction (V2 — Dev Terminal / OS)
- **Concept:** the whole portfolio is a tasteful developer workstation / tiling-window-manager OS. Content maps onto real dev tooling so it reads as authentic, not gimmicky: Hero = a terminal with a typed boot sequence (`whoami`, `cat intro.txt`), About = a `neofetch` system readout, Timeline = `git log --graph`, Skills = `tree`, Work/Projects = windowed repo panes, Nav = a workspace switcher, plus a vim/tmux-style bottom status bar (mode • path • location • clock).
- **Dark-first** with a light "paper terminal" toggle. The dark surface is a deep blue-slate near-black (never pure black), derived from the brand blue (#599fc0).
- **Palette:** blue brand (primary / active / keywords) + **green** (prompts `$`, success ✓, strings) + **amber** (highlights, numbers, "HEAD") used like *syntax tokens* — multiple accents are justified because they map to syntax highlighting, but stay disciplined (foreground/muted carry ~90% of the weight). Neutrals tinted toward the blue hue. OKLCH throughout.
- **Typography:** **JetBrains Mono** carries the UI, prompts, and headings (a real, characterful mono — never lazy "mono = technical"); **Mona Sans** (`.prose-sans`) carries all long-form body copy for readability; **Silkscreen** pixel face only for tiny HUD labels / the neofetch logo (gaming flair seasoning).
- **Signature moments:** the typed Hero boot sequence, the `git log` timeline, the `neofetch` about block, and the workspace-switcher nav with number-key (1–7) shortcuts.
- **Anti-references:** generic AI-slop dev portfolios — cyan-on-black neon, purple→blue gradient text, identical icon-topped feature cards, glassmorphism everywhere, fake stat/sparkline decoration, colored left/right border stripes. Also avoid the *lazy* terminal cliché (all-green mono on pure black). None of these.
- **Motion:** balanced — the orchestrated Hero boot type-on, staggered scroll reveals, crisp (non-gooey) sliding nav indicator, keycap button feedback. Honor `prefers-reduced-motion` everywhere (boot sequence renders fully, no blink).

### Design Principles
1. **Authentic metaphor, not costume.** Every terminal device must map to something real about how Abraham works; if a metaphor is just decoration, cut it.
2. **Readable first.** Mono for UI/labels, real sans for paragraphs. Never sacrifice legibility for theme.
3. **Color = syntax, used sparingly.** Green/amber/blue carry meaning (prompt/highlight/primary); everything else is foreground/muted.
4. **Fast and quiet.** Static output, self-hosted fonts, transform/opacity-only animation, no cursor-tracking or heavy JS.
5. **Real content over filler.** Copy reflects the actual NJDCA role, AI-assisted workflow, and shipped projects — no lorem, no invented achievements.
